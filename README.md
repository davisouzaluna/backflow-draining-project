O projeto propõe o desenvolvimento de um sistema de monitoramento virtual capaz de monitorar pontos de alagamento no recife, utilizando os dados de chuva e maré.

A proposta é analisar os dados disponíveis de chuva da APAC e dados de maré da Marinha do Brasil e observar relações entre condições ambientais e  locais ou os períodos em que ocorreram os alagamentos.

O problema abordado é a ocorrência de alagamentos durante períodos de chuva no Recife. Quando chove muito a quantidade de água pode ser maior do que a capacidade de escoamento da drenagem, fazendo com a água se acumule nas ruas e possa retornar pelos pontos de drenagem.

Também iremos observar a influência da maré nessa situação, principalmente quando ocore chuvas mais intensa nos períodos em que a maré esta alta. 

A ideia central do projeto é observar os dados de chuva e maré, para identificar condições que possam esta relacionada a esses eventos de alagamento . 

A solução será baseada em um sensor virtual, responsável por coletar os dados de chuva disponibilizados pela APAC e os dados de maré disponibilizados pela Marinha do Brasil.
