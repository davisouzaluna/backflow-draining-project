O projeto propõe o desenvolvimento de um sistema de monitoramento virtual capaz de identificar pontos de alagamento no Recife, a partir de dados de chuva e de maré.
A proposta consiste em analisar os dados pluviométricos disponíveis disponibilizados pela APAC e dados de maré fornecidos pela Marinha do Brasil, buscando relações entre essas condições ambientais e os locais e períodos em que os alagamentos ocorrem.
O problema abordado é a ocorrência de alagamentos no Recife durante períodos de chuva intensa. Quando o volume de água ultrapassa a capacidade de escoamento do sistema de drenagem, a água se acumula nas ruas e retorna pelos próprios pontos de drenagem.
O projeto também irá analisar também a influência da maré nesse processo, principalmente nos casos em que chuvas intensas coincidem com períodos de maré alta. Essa condição está associada ao fenômeno de alagamento composto(compound flooding), no qual a elevação do nível do mar reduz a capacidade de escoamento da drenagem e intensifica o acúmulo de água nas vias, fenômeno já registrado em outras cidades costeiras de baixa altitude. 
A ideia central do projeto é observar os dados de chuva e maré, para identificar as condições relacionadas à ocorrência desses eventos de alagamento . 
A solução proposta é um sensor virtual, responsável por integrar os dados da chuva disponibilizados pela APAC e os dados de maré disponibilizados pela Marinha do Brasil.
